# 项目概述

[项目首页](../../README.md) · [文档目录](README.md) · [日本語](../ja/01-overview.md)

## 项目定位

LabReportTex 是一套用于日文实验报告的 LaTeX 模板，面向日本工学部课程中常见的实验报告写作场景。它以 LuaLaTeX 和 `ltjsarticle` 为基础，提供报告基本信息表、页眉、日文排版、章节文件和参考文献入口等已经配置好的结构。

项目同时维护中文和日文说明，并用一份虚构的 RC 低通滤波器报告展示模板源码与编译结果的对应关系。

正常使用时不需要了解仓库的开发历史，也不需要 Git。项目公开发布后，请从最终公开仓库的 [Releases 页面](https://github.com/ywhdt/LabReportTex/releases) 下载干净模板 ZIP，解压后直接开始填写。仓库中的说明文档和完整示例不会放入该 ZIP，但可以继续在线查阅。

## 适用对象

本模板适合已经安装并能基本使用 LaTeX 的学生，例如知道如何打开 `.tex` 文件、运行编译命令，以及阅读编译错误。即使还不熟悉日文实验报告的 LaTeX 写法，也可以先依照前六篇文档完成一份基础报告。

模板尤其适合下面的情况：

- 课程没有提供可直接使用的 LaTeX 模板，或只给出了格式要求；
- 希望将报告基本信息、页眉、正文和参考文献分开放置；
- 需要用 LuaLaTeX 编写日文、英文、数字和数学公式混排的报告；
- 希望在修改前先查看完整示例的源码和 PDF 效果。

## 设计目标

模板的目标是让实验报告从一个干净、可编译的起点开始，不包含课程内容或写作结论。下载后的目录中，报告信息集中在 `config/metadata.tex`，正文按章节放在 `sections/`，图片和参考文献也有固定位置。根文件 [report.tex](../../template/report.tex) 负责把这些部分组合起来。

默认配置保持必要功能：日文排版、常用表格与公式、交叉引用、超链接和参考文献。TikZ、CircuitikZ、代码清单和 PGFPlots 等较重的功能以可选模块提供，需要时再启用。

模板最低支持 TeX Live 2026。文档中的命令和路径以 Release ZIP 内的干净模板为准；需要深入理解元数据、章节、公式或可选模块时，可继续沿用目录中的后续文章。

完整示例提供源码、功能索引和编译结果三方对照。可以先在[示例功能索引](../../examples/FEATURES.md)中查找 `CORE-JAPANESE-01`、`TITLEBLOCK-01` 和 `STRUCT-SECTION-01`，再分别查看日文混排、基本信息表和章节结构在[示例源码](../../examples/source/rc-low-pass-filter)与[示例 PDF](../../examples/compiled/rc-low-pass-filter.pdf)中的位置。

## 不包含的范围

LabReportTex 不是学校、学院或课程的官方模板，也不会替代授课教师给出的封面、章节顺序、引用规范或提交要求。开始写作前，应先确认课程是否要求指定模板、指定编译方式或额外文件。

本项目也不提供 LaTeX 安装程序、编辑器使用教程或实验内容的技术指导。若本机尚未具备可用的 LaTeX 环境，请先完成安装，再阅读下一篇的环境检查方法。对模板实现、绘图、代码清单和参考文献样式的详细说明会在后续文档中给出。
