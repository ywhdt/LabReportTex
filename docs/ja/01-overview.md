# プロジェクト概要

[プロジェクトトップ](../../README.md) · [ドキュメント目次](README.md) · [中文](../zh-CN/01-overview.md)

## プロジェクトの位置付け

LabReportTex は、日本の工学部の授業でよく使われる実験レポートを作成するための LaTeX テンプレートです。LuaLaTeX と `ltjsarticle` を基盤とし、レポートの基本情報表、ヘッダー、日本語組版、セクション別の本文ファイル、参考文献を利用するための設定をあらかじめ用意しています。

このプロジェクトでは、中国語と日本語の説明を併せて提供しています。また、架空の RC 低域通過フィルタのレポートを使い、テンプレートのソースと組版結果の対応を示しています。

通常の利用では、[Releases ページ](https://github.com/ywhdt/LabReportTex/releases) からクリーンなテンプレート ZIP をダウンロードしてご利用ください。リポジトリの説明文書と完全なサンプルは ZIP に含まれませんが、引き続きオンラインで参照できます。

## 対象読者

このテンプレートは、LaTeX をインストール済みで基本的な使い方を知っている学生を対象としています。たとえば、`.tex` ファイルを開く、コンパイルコマンドを実行する、コンパイルエラーの内容を確認する、といった操作ができれば十分です。日本語の実験レポートを LaTeX で書くことにまだ慣れていなくても、最初の 6 本の文書に従えば基本的なレポートを作成できます。

特に、次のような場合に向いています。

- 授業からそのまま使える LaTeX テンプレートが配布されていない、または書式要件だけが示されている場合
- レポートの基本情報、ヘッダー、本文、参考文献を分けて管理したい場合
- LuaLaTeX で日本語、英語、数字、数式を混在させたレポートを作成する場合
- 変更する前に、完成したサンプルのソースと PDF での組版結果を確認したい場合

## 設計目標

このテンプレートの目的は、すぐにコンパイルできるクリーンな状態から実験レポートを書き始められるようにすることです。授業内容やレポートの結論は含みません。展開後のディレクトリでは、レポート情報を `config/metadata.tex` に、本文を `sections/` の各セクションファイルにまとめ、画像と参考文献にも決まった置き場所を設けています。ルートファイルの [report.tex](../../template/report.tex) がこれらを順に読み込みます。

初期設定には、日本語組版、よく使う表と数式、相互参照、ハイパーリンク、参考文献が含まれます。TikZ、CircuitikZ、コードリスト、PGFPlots など追加パッケージを必要とする機能は、必要になった時点で有効にするオプションモジュールです。

このテンプレートの最低対応環境は TeX Live 2026 です。文書中のコマンドとパスは、Release ZIP に含まれるクリーンなテンプレートを基準にしています。メタデータ、セクション、数式、オプションモジュールを詳しく扱う際は、以降の文書を参照してください。

完成したサンプルでは、ソース、機能一覧、コンパイル結果を相互に参照できます。まず[サンプル機能一覧](../../examples/FEATURES.md)で `CORE-JAPANESE-01`、`TITLEBLOCK-01`、`STRUCT-SECTION-01` を探すと、日本語組版、基本情報表、セクション構成の位置を[サンプルソース](../../examples/source/rc-low-pass-filter)と[サンプル PDF](../../examples/compiled/rc-low-pass-filter.pdf)で順に確認できます。

## 対象外の範囲

LabReportTex は大学、学部、授業が提供する公式テンプレートではなく、担当教員が定める表紙、章の順序、引用形式、提出要件に代わるものでもありません。作成を始める前に、授業で指定されたテンプレート、コンパイル方法、追加ファイルがないかを確認してください。

また、本プロジェクトは LaTeX のインストーラ、エディタの使い方の解説、実験内容に関する技術指導を提供しません。まだ利用可能な LaTeX 環境がない場合は、まず環境を整えてから次の文書にある確認方法を読んでください。テンプレートの実装、図、コードリスト、参考文献スタイルの詳細は後続の文書で扱います。
