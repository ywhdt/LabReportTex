## まず完成したサンプルを見る

テンプレートで何ができるかを先に知りたい場合は、[サンプル PDF](../../examples/compiled/rc-low-pass-filter.pdf)をご覧ください。黒い本文は一つの架空の実験レポートとして読め、色付きの説明と灰色のコード欄で使い方を簡単に確認できます。続けて調べる場合は、[サンプルソース](../../examples/source/rc-low-pass-filter/)と[機能一覧](../../examples/FEATURES.md)を対応させてください。
