## 中文

LabReportTex 是一个面向日本工学部学生、用于编写实验报告的 LaTeX 模板，由作者在数月的实际使用过程中逐步整理而成，并提供中文和日文说明。

使用时，可以直接从 [Releases](https://github.com/ywhdt/LabReportTex/releases) 下载干净的模板 ZIP，无需克隆整个仓库。

项目通过模板源码、说明文档和编译结果之间的对照，帮助已经具备少量 LaTeX 基础的同学理解模板的用法，并根据自己的实际需要进行调整。本项目不是任何学校的官方模板。

如果不知道从哪里开始，可以先看[完整示例 PDF](examples/compiled/rc-low-pass-filter.pdf)。其中黑色文字是一篇完整的虚构实验报告，彩色日文说明和灰色源码框会在对应位置简要介绍用法。也可以直接查看[示例源码](examples/source/rc-low-pass-filter/)或[功能索引](examples/FEATURES.md)。

## 日本語

LabReportTex は、日本の工学部学生向けの実験レポート用 LaTeX テンプレートです。作者が数か月間、実際に使用しながら少しずつ整えてきたテンプレートをもとに、中国語と日本語の説明を用意しています。

利用時は、[Releases](https://github.com/ywhdt/LabReportTex/releases) から空のテンプレートを ZIP 形式でダウンロードでき、リポジトリ全体をクローンする必要はありません。

テンプレートのソース、説明ドキュメント、コンパイル結果を見比べながら、LaTeX の基礎を少し理解している学生が使い方を確認し、自分の用途に合わせて調整できる構成を目指しています。本プロジェクトは特定の大学が提供する公式テンプレートではありません。

どこから始めればよいか迷った場合は、まず[完成したサンプル PDF](examples/compiled/rc-low-pass-filter.pdf)をご覧ください。黒い文章は一つの架空の実験レポートとして読め、色付きの日本語説明と灰色のコード欄で使い方を簡単に確認できます。[サンプルソース](examples/source/rc-low-pass-filter/)と[機能一覧](examples/FEATURES.md)から詳しい箇所を探すこともできます。
